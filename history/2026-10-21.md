## 1. [Claude Cowork plugin set (knowledge-work-plugins)](https://github.com/anthropics/knowledge-work-plugins)
Source: GitHub Trending
Anthropic open-sourced a plugin marketplace of 11 role-specific plugins (sales, finance, legal, PM, and others). ~30.8k stars. File-based (markdown/JSON, no code, no build steps), installed via `claude plugin install sales@knowledge-work-plugins`. Bundles domain-specific slash commands and auto-applied skills; built for Claude Cowork, compatible with Claude Code.
Why it matters: Gives teams ready-made, no-code Claude configurations for specific job functions, lowering the bar for non-engineers to customize Claude for their workflow.

## 2. [vLLM](https://github.com/vllm-project/vllm)
Source: GitHub Trending
High-throughput, memory-efficient LLM inference/serving engine. 94.4k GitHub stars, 200+ HF model architectures, PagedAttention, continuous batching, speculative decoding, disaggregated prefill/decode across NVIDIA/AMD/Intel/TPU. Originated at UC Berkeley Sky Computing Lab. OpenAI-compatible server + native Anthropic Messages API support.
Why it matters: One of the most widely adopted open-source inference engines; broad hardware/model support makes it a default choice for self-hosting LLMs at scale.

## 3. [Anthropic — Preparing for the 2026 US midterms](https://www.anthropic.com/news/2026-us-midterms)
Source: Anthropic blog

Partnered with Institute for Strategic Dialogue and McCain Institute to stress-test defenses.

## 4. [Cloudflare's security-audit-skill](https://github.com/cloudflare/security-audit-skill)
Source: GitHub Trending
MIT-licensed, ~34.2k stars. 6-phase pipeline (recon, coverage-led hunting, candidate validation, structured JSON findings, independent verification, reporting) with separate hunter/verifier agents. Requires an OS-enforced sandbox to execute target code. Cloudflare's README states a single run found roughly half the vulnerabilities that repeated runs found combined.
Why it matters: A rare case of a major infra company open-sourcing its internal AI-agent security-audit workflow, with built-in adversarial self-verification to cut false positives.

## 5. [ASPIRE](https://github.com/NVlabs/ASPIRE)
Source: GitHub Trending (NVIDIA Labs)
Framework using coding agents (Claude Code, Codex) to discover/refine robot manipulation skills instead of gradient-descent training. v1.0 (Oct 2026) reports 99% success on 80 LIBERO-Pro tasks plus unspecified "selected" Robosuite and BEHAVIOR-1K tasks. On 10 LIBERO-Pro tasks, success rose from 15% (GPT-6 Luna) to 99% (Claude Opus 5.5). Pairs a simulation agent with a real-robot "System 2" agent; physical demos include Rubik's Cube, bottle-cap unscrewing, cup nesting. Paper: arXiv:2607.00272.
Why it matters: Suggests coding agents can replace gradient-descent training for certain robotics skill acquisition, with large reported jumps from swapping in stronger LLMs.

## 6. [Kronos](https://github.com/shiyu-coder/Kronos)
Source: GitHub Trending
Open-source decoder-only foundation model pretrained on candlestick (K-line) data from 45+ exchanges, accepted to AAAI 2026. Two-stage: tokenizer + autoregressive Transformer. Four sizes, Kronos-mini (4.1M params) to Kronos-large (499.2M params, not open-sourced). MIT-licensed; Qlib-based A-share backtest example + live BTC/USDT demo; explicitly NOT production-ready for trading.
Why it matters: First open-source foundation model purpose-built for financial candlestick data, giving researchers a ready baseline for quant/trading-signal experimentation.

## 7. [ruflo](https://github.com/ruvnet/ruflo) (formerly "Claude Flow")
Source: GitHub Trending
Multi-agent orchestration harness on Claude Code/Codex, coordinating "100+" agents (README internally inconsistent, also says 98 elsewhere). MIT-licensed, ~77.8k stars. Hierarchical/mesh/adaptive topologies, HNSW-indexed vector memory, cross-machine federation with mTLS/ed25519, ~35 plugins (also internally inconsistent). Self-reported "89% accuracy" and benchmark wins over LangGraph/AutoGen/CrewAI without disclosed methodology. Installed "mods" run unsandboxed.
⚠️ unverified: source README has internal inconsistencies in its own numbers (agent/plugin counts) — treat benchmark claims skeptically.
Why it matters: A widely-starred orchestration layer for coordinating large agent swarms, but self-reported benchmarks and inconsistent numbers warrant skepticism despite popularity.

## 8. [CLI-Anything](https://github.com/HKUDS/CLI-Anything)
Source: GitHub Trending
Auto-generates agent-friendly CLIs for existing software. Apache-2.0, ~55.7k stars. 7-phase pipeline integrates with Claude Code/Cursor/Codex. ~2,460 passing tests (source cites slightly varying numbers in different sections) across 18+ generated CLIs including GIMP, Blender, LibreOffice, ComfyUI. Generated CLIs wrap real backends, support --json output, distributed via "CLI-Hub" registry.
Why it matters: A practical building block for giving AI agents reliable, scriptable control over GUI-only legacy software.
