9. **[MadsLorentzen/ai-job-search — Claude Code-based job-search agent framework](https://github.com/MadsLorentzen/ai-job-search)**
Source: GitHub Trending
MadsLorentzen released "ai-job-search," an open-source, locally-run job-application framework built on Claude Code (53.1k stars, 17.4k forks, MIT-licensed). It uses slash commands (/setup, /scrape, /apply, /rank, /interview, /outcome, and others) to scrape/rank jobs, draft and LaTeX-compile tailored CVs/cover letters with ATS checks, run mock interviews, and track outcomes via an HTML dashboard. Uses a drafter-reviewer multi-agent pattern, stores the candidate profile in CLAUDE.md, includes country-specific scraping skills, offers optional read-only Notion sync and approval-gated Gmail sync via MCP. README candidly states its data-handling safeguards are instruction-level rather than sandboxed, that Claude Code requires a paid subscription or API credits (no free tier), and that its LinkedIn scraping skill — while using public, unauthenticated endpoints — explicitly violates LinkedIn's Terms of Service if used at volume.
Why it matters: A concrete, highly-starred example of Claude Code repurposed as a general-purpose local agent framework beyond coding — though its own README candidly flags the LinkedIn ToS breach and non-sandboxed security model.
