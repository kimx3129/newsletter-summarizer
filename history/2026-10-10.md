## 1. [Introducing Claude Haiku 5.5](https://www.anthropic.com/claude-haiku-5-5)
Source: Anthropic News — ✅ verified

- Anthropic released Claude Haiku 5.5, a small model positioned as its cheapest and fastest to date, intended for high-volume tasks like summarization, classification, and database queries, and usable as a subagent alongside Opus 5.5 and Sonnet 5.5.
- It prices at $0.10/$0.50 per million input tokens and $0.50/$2.50 per million output tokens (≤100k/>100k context), roughly 75% cheaper to run than Haiku 4.5, and scores 72.4% on OSWorld 2.1 offline versus Haiku 4.5's 15.7%; it is also the first Haiku model with an adjustable effort setting.
- Customers reported concrete gains: Asana saw over 30% lower latency, Box scored 11 points higher than Haiku 4.5 at roughly half the latency, and HubSpot hit 92.8% on its CRM benchmark suite; Sonnet 5.5 cache-read pricing was also cut in half as part of the same update.

Why it matters: Developers building high-volume agentic or classification pipelines get a markedly cheaper, faster small model without the accuracy cliff that typically comes with "cheap" tiers, shifting the cost calculus for large-scale Claude deployments.

## 3. [lingbot-map — geometric context transformer for streaming 3D reconstruction](https://github.com/Robbyant/lingbot-map)
Source: GitHub Trending (ECCV 2026 Best Paper candidate) — ✅ verified

- LingBot-Map is an open-source feed-forward 3D foundation model for streaming 3D reconstruction, built around a Geometric Context Transformer (GCT) that combines coordinate grounding, dense geometric cues, and long-range drift correction.
- It uses paged KV-cache attention for streaming inference, claims about 20 FPS at 518×378 resolution on sequences over 10,000 frames, and is listed as an ECCV 2026 Best Paper Award candidate (not a confirmed winner); the paper is also on arXiv (2604.14141).
- The repo has roughly 17.7k stars and ~2k forks under Apache-2.0, ships checkpoints on Hugging Face/ModelScope, an interactive viewer, and evaluation scripts across benchmarks like KITTI, ETH3D, and Tanks and Temples, though the README gives no numerical benchmark comparisons.

Why it matters: Researchers and robotics/SLAM engineers get an open, real-time-capable 3D reconstruction model that could replace slower iterative optimization pipelines in applications like robotics mapping and AR.

## 4. [unsloth — local UI for running/training LLMs and diffusion models](https://github.com/unslothai/unsloth)
Source: GitHub Trending — ✅ verified

- Unsloth is an open-source toolkit (77.7k stars) for running and fine-tuning LLMs and diffusion models locally, available as a desktop app, a web UI ("Studio"), or a Python package.
- It claims roughly 2x faster fine-tuning with 70% less VRAM and no accuracy loss, 12x faster MoE training, and support for LoRA, QLoRA, full fine-tuning, GRPO, and DPO across models including Qwen3.8, DeepSeek-V4, Gemma 4, and FLUX.
- Recent updates add AMD GPU support, an `unsloth start` command to connect Claude Code and Codex to local models, and an MCP server integration; the core package is Apache-2.0 while the Studio UI is AGPL-3.0.

Why it matters: Developers and researchers without large GPU budgets get faster, cheaper local fine-tuning and now a path to wire local models directly into coding agents via MCP, reducing reliance on cloud inference APIs.

## 7. [rea — reverse engineering agent toolkit](https://github.com/morluto/rea)
Source: GitHub Trending — ✅ verified (corrected)

- REA ("Reverse Engineer Anything") is an open-source MCP server and CLI that lets AI agents like Claude Code, Cursor, and Codex reverse-engineer binaries, apps, and runtime behavior.
- It supports native binaries via Hopper/Ghidra/IDA, ELF files, EVM bytecode, Android APKs (via JADX), .NET assemblies, Electron/JS apps, firmware (via Binwalk/Unblob), and network captures, returning findings with supporting evidence.
- The project has roughly 45.7k stars and 7.3k forks under an MIT license, with case studies including analyzing DX-Ball, Notion's Electron clipboard bridge, and a 1990s PC-98 game (TH04).

Why it matters: Security researchers and developers get a standardized agent interface for reverse engineering across many binary and application formats, lowering the barrier to AI-assisted vulnerability research and compatibility reimplementation.

## 8. [litellm — unified AI gateway for 100+ LLM APIs](https://github.com/BerriAI/litellm)
Source: GitHub Trending — ✅ verified

- LiteLLM is an open-source AI gateway and Python SDK providing a single OpenAI-compatible interface to over 100 LLM providers, usable as a library or as a standalone proxy server for teams.
- It has about 60.7k stars and 12.2k forks, supports chat, embeddings, image, audio, and rerank endpoints, and claims 8ms P95 latency at 1,000 requests per second; it also integrates MCP servers and agent harnesses like Claude Code and OpenCode.
- Gateway features include virtual keys, spend tracking, guardrails, load balancing, and an admin dashboard, with Docker/Helm/Terraform deployment options for AWS and GCP; a commercial license adds SSO and enterprise support.

Why it matters: Platform teams and agent builders get a vendor-agnostic routing layer that avoids lock-in to any single LLM provider while centralizing cost tracking and access control across an organization's AI usage.
