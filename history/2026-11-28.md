## 1. [heretic](https://github.com/p-e-w/heretic)
Source: GitHub Trending
- Open-source tool that modifies language model behavior — removing refusals, suppressing "slop," reducing sycophancy — without any fine-tuning or retraining.
- Pairs two swappable modifiers (default Arbitrary-Rank Ablation, plus directional "abliteration") with a TPE-based Optuna hyperparameter search optimizing against scorers like refusal rate and KL divergence; ~30-40 min on an RTX 3090 for a model like Qwen3-4B-Instruct-2507; works on most dense, several MoE, and many hybrid/multimodal architectures (4-bit quantization optional).
- ~43.5k stars/5.5k forks, AGPL-3.0, ships reproduction manifests; community has already published thousands of Heretic-modified models to Hugging Face via the "Heretic Grimoire" catalog.

Why it matters: Lowers the cost of uncensoring or steering open-weight models from an expensive fine-tuning job to a half-hour automated search, accelerating the spread of modified/unaligned model variants that downstream users and safety teams will need to account for.

Status: ✅ verified

## 2. [CLI-Anything](https://github.com/HKUDS/CLI-Anything)
Source: GitHub Trending
- From the HKUDS lab: a pipeline that automatically generates command-line interfaces for existing desktop and web software so AI agents can control them.
- A 7-phase process analyzes a target app's source, designs commands/state handling, builds a Click-based CLI with REPL and `--json` output, writes/runs tests, and documents the result; generated CLIs delegate to the real app backend (e.g., LibreOffice, Blender's Python API) rather than reimplementing features, each shipping a `SKILL.md` for agent discovery, with 2,400+ tests passing.
- Covers dozens of tools across creative (GIMP, Blender, Audacity, Krita), office (LibreOffice, Zotero, Obsidian), engineering (FreeCAD, QGIS), and AI/ML (ComfyUI, Ollama) categories, plus a "CLI-Hub" package manager and integrations for Claude Code, Cursor, Codex, and other agent hosts; ~67k stars, Apache-2.0.

Why it matters: Addresses a core bottleneck for AI agents — most software has no machine-usable interface — by auto-generating one, potentially letting agents operate a much wider range of existing apps without each vendor building its own API.

Status: ✅ verified

## 3. [last30days-skill](https://github.com/mvanhorn/last30days-skill)
Source: GitHub Trending
- MIT-licensed AI agent skill that researches a topic across Reddit, X, YouTube (with transcripts), Hacker News, Polymarket, and the general web, restricted to roughly the past 30 days.
- Invoked as `/last30days <topic>` (person, company, product, or "X vs Y"), ranks results by engagement signals (upvotes, likes, prediction-market volume), merges duplicate coverage into clusters; can optionally pull from TikTok, Instagram, LinkedIn, Bluesky, and Threads with added credentials (Reddit, HN, Polymarket, GitHub work with no keys).
- Installs as a plugin for Claude Code, Grok, and OpenClaw, via `npx skills` for Codex/Cursor/Gemini CLI, or as a download for claude.ai/Claude Desktop; requires Python 3.12+ plus yt-dlp.

Why it matters: Gives developers and researchers a drop-in way to get a recency-weighted, cross-platform "what are people actually saying" brief instead of relying on search-engine aggregation — useful for competitive tracking, trend-spotting, or meeting prep.
