1. **Anthropic Donates Agent Skills to the New Agentic AI Foundation** — https://www.anthropic.com/news/donating-agent-skills-to-the-agentic-ai-foundation, https://github.com/anthropics/skills
   Source: Anthropic News (primary); GitHub (anthropics/skills)
   Summary: Anthropic announced on Oct 22, 2026 it's donating the Agent Skills open standard (name, logo, agentskills.io domain, GitHub org) to the Agentic AI Foundation (AAIF), a Linux Foundation project co-founded by Anthropic, Block, and OpenAI in 2025. Skills launched Oct 2025, became a published standard Dec 2025; 70+ platforms support it (ChatGPT, Cursor, GitHub Copilot, VS Code); 1M published skills, ~280M installs; David Soria Parra and Mahesh Murag are Lead Maintainers. Follows Anthropic's earlier MCP donation to the same foundation; anthropics/skills repo has ~186k stars, ~22k forks; most skills Apache 2.0 (document skills remain source-available).
   Why it matters: Moving Skills to a vendor-neutral foundation alongside MCP signals ceding direct control over widely-adopted infrastructure.
   Status: ✅ verified

2. **lightpanda-io/browser — headless browser built for AI agents** — https://github.com/lightpanda-io/browser
   Source: GitHub
   Summary: Headless browser written from scratch in Zig (not a Chromium/WebKit fork), targeting AI agents/automation. Exposes CDP and WebDriver BiDi servers compatible with Puppeteer/Playwright, an agent mode for LLM-driven browsing, a native MCP server, and a `fetch` command dumping HTML/Markdown/PNG/PDF/structured data; 39.2k stars, 1.9k forks, AGPL-3.0. Vendor benchmark (933 pages, AWS EC2 m5.large) claims 123MB peak memory vs 2GB for headless Chrome (~16x lighter) and 5s vs 46s for 100 pages (~9x faster) — vendor-reported, not independently verified.
   Why it matters: could cut infra cost/latency for browser-using agents if the performance claims hold up.
   Status: ✅ verified

3. **Orkas-AI/Orkas — local-first "AI team" desktop app** — https://github.com/Orkas-AI/Orkas
   Source: GitHub
   Summary: MIT-licensed, local-first desktop app; a "Commander" agent coordinates 16 built-in specialist agents; can also run external CLI agents (Claude Code, Codex, OpenCode, OpenClaw, Hermes-Agent); supports scheduled automations and connectors (Gmail, Notion, Slack, Shopify, Stripe) requiring confirmation; local SQLite vector search; ~6.2k stars, 371 forks. Built on Electron/TypeScript/Node 22+; installers for macOS/Windows (Linux from source only); free with 500 model credits, paid tiers from $11.99/month.
   Why it matters: a persistent local multi-agent "team" alternative to hosted orchestration products.
   Status: ✅ verified

4. **The-PR-Agent/pr-agent — open-source AI PR reviewer** — https://github.com/The-PR-Agent/pr-agent
   Source: GitHub
   Summary: Community-maintained open-source AI code review tool, originally built by Qodo, distinct from Qodo's separate commercial product (Qodo 2.0, formerly Qodo Merge); reportedly being donated to an open-source foundation. Commands /describe, /review, /improve, /ask, /similar_issue, ~30s per run via a single LLM call; supports GitHub/GitLab/Bitbucket/Azure DevOps/Gitea; CLI/GitHub Actions/Docker/webhook deployment; works with OpenAI/Claude/Gemini/DeepSeek/Mistral/Ollama via LiteLLM. 13.8k stars, 2.0k forks, MIT; /help_docs disabled since v0.36.1 pending a fix for a credential-exposure issue; just gained its first external maintainer.
   Why it matters: foundation governance offers continuity assurance, but the credential-exposure issue is a caution.
   Status: ✅ verified

5. **superdesigndev/treg — marketplace hub for agent tools** — https://github.com/superdesigndev/treg
   Source: GitHub
   Summary: "OpenRouter, but for agent tools instead of models" — a single base URL/token for a catalog of thousands of tool endpoints, priced per call "from a cent." Uses a "credential ladder" (team's own key/stored secret first, then free public routes, then treg's metered key); team-shared API keys/skills/CLIs stay server-side; has a Claude Code plugin + Claude.ai connector; "Arenas" compare providers; 6.9k stars, 598 forks, Apache 2.0 with terms barring competing hosted resale. Hosted service at treg.to, task-based search, $1.00 free credit for new accounts; self-hosting supported.
   Why it matters: centralizes tool discovery/billing the way OpenRouter did for models.
   Status: ✅ verified

6. **Donchitos/Claude-Code-Game-Studios — 49-agent game-dev studio simulation** — https://github.com/Donchitos/Claude-Code-Game-Studios
   Source: GitHub
   Summary: Open-source (MIT) template turning Claude Code into a simulated game studio: 49 specialized agents in a 3-tier hierarchy, ~70 skills (README lists 74; repo's About section says 72), 15 validation hooks, 62 document templates; supports Godot 4, Unity, Unreal Engine 5. A `modes.rigor` setting (minimal/standard/full, default minimal) controls process overhead; directors use Opus, the lead-programmer plus 15 other specialists (16 roles) use Sonnet, remaining agents inherit the session model; agents must ask approval before writing changes. ~31.2k stars, 4.3k forks; author's internal test built 4 games from one brief at different rigor levels — "standard" ranked last by blind reviewers/playtesters, i.e. more documentation didn't improve game quality.
   Why it matters: a data point against heavy agent-hierarchy setups vs. simpler workflows.
   Status: ✅ verified (corrected) — note: README/About discrepancy on skill count (70 vs. 72/74) left visible above rather than silently resolved.
