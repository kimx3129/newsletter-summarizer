## 3. [cognee — open-source AI memory platform](https://github.com/topoteretes/cognee) ✅ verified (corrected)

Local-first memory system giving agents persistent, structured long-term memory using small models, no API keys required for local operation. Uses a knowledge-graph + vector hybrid via remember/recall/improve operations; supports multiple storage backends including PostgreSQL+PGVector and a traditional graph-DB/vector-store/Redis/relational-DB stack; 31.5k stars, 3.2k forks, Apache 2.0. Offers migration/interoperability (via a COGX exchange format) from Mem0, Letta, Zep, and Graphiti.

**Why it matters:** Self-hostable, dependency-light memory layer for long-running agents.

## 4. [Anthropic expands Cyber Verification Program](https://www.anthropic.com/news/cyber-verification-program) ✅ verified (corrected)

Anthropic consolidated Project Glasswing and its original Cyber Verification Program into a unified three-tier system for vetted security professionals with reduced safeguards. Tiers: Defense Access (days, defensive/malware analysis), Red Team Access (weeks, authorized pentesting, orgs only), Specialized Access (critical infrastructure, requires US government collaboration). Project Glasswing partners found 129,000+ verified vulnerabilities (April–July 2026); Anthropic's own open-source scanning found an additional 5,500 (April–October 2026); 33,000+ of the combined total rated critical/high severity. All tiers get Opus 5.5/Sonnet 5.5/Mythos 5.1; data retention mandatory unless zero-data-retention via Fable 5.1/Mythos 5.1, pending future Enterprise Frontier Safeguards.

**Why it matters:** Formal pathway to dual-use capabilities for security teams; concrete vulnerability-discovery data point.
