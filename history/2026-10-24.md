# 📰 Tech/AI Daily Digest — 2026-10-24

## 1. [Donating Agent Skills to the Agentic AI Foundation](https://www.anthropic.com/news/donating-agent-skills-to-the-agentic-ai-foundation)
**Source:** Anthropic News
**Status:** ✅ verified

1. Anthropic is donating the Agent Skills open standard — name, logo, GitHub org, agentskills.io domain — to the Agentic AI Foundation (AAIF), a Linux Foundation project co-founded with Block and OpenAI in 2025 (which earlier received Anthropic's donated MCP).
2. Agent Skills launched Oct 2025, became an open standard Dec 2025, and is now integrated into 70+ platforms (ChatGPT, Cursor, GitHub Copilot, VS Code) with ~1M skills published and ~280M installs.
3. David Soria Parra and Mahesh Murag are Lead Maintainers; engineers from Anthropic, Google, and OpenAI maintain it under AAIF governance.

**Why it matters:** Reduces single-vendor lock-in risk for a widely-adopted agent-tooling standard, mirroring the earlier MCP donation.

**Source:** GitHub Trending

## 3. [Unlimited-OCR — One-Shot, Long-Horizon Document Parsing Model](https://github.com/baidu/Unlimited-OCR)
**Source:** GitHub Trending
**Status:** ✅ verified

1. Baidu open-sourced Unlimited-OCR, successor to the DeepSeek-OCR approach, handling images, multi-page docs, and PDFs with a 32,768-token max output and "gundam"/"base" input configs.
2. Inference is supported via HF Transformers, vLLM, and SGLang; MIT licensed, weights on Hugging Face, arXiv paper 2606.23050. ~28.3k stars, 3.0k forks, 160 watchers.
3. No published benchmark scores despite referencing OmniDocBench.

**Why it matters:** A fully open, MIT-licensed OCR model at scale could undercut commercial document-AI offerings, though unverified benchmark claims warrant caution.
