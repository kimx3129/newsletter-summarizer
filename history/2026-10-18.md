## 6. ai-memory
- Source: GitHub Trending
- URL: https://github.com/akitaonrails/ai-memory

- Why it matters: Vendor-neutral shared memory lets developers switch coding-agent tools without losing context.

## 7. xerj
- Source: GitHub Trending
- URL: https://github.com/xerj-org/xerj
