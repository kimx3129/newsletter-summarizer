2. **shiyu-coder/Kronos — open-source foundation model for financial market data** — https://github.com/shiyu-coder/Kronos
   Source: GitHub Trending
   Summary: First open-source foundation model for financial candlestick (K-line) data, pretrained on data from 45+ global exchanges. Two-stage design: specialized tokenizer converts OHLCV data into hierarchical discrete tokens, then an autoregressive decoder-only Transformer is pretrained on those tokens. Four sizes: Kronos-mini (4.1M params), Kronos-small (24.7M), Kronos-base (102.3M), Kronos-large (499.2M, not open-sourced). arXiv 2508.02739, accepted AAAI 2026. Ships a KronosPredictor class, a Qlib-based finetuning pipeline, and a backtest explicitly described as a demo, not a production trading system. MIT licensed, ~45.4k stars/7.5k forks.
   Why it matters: Gives quant researchers and fintech developers a free, pretrained starting point for market-forecasting experiments instead of training time-series models from scratch, though lack of published benchmarks means real-world edge is unproven.
   Status: ✅ verified

3. **ifixai-ai/iFixAi — independent auditing tool for AI agents** — https://github.com/ifixai-ai/iFixAi
   Source: GitHub Trending
   Summary: Open-source Python tool that independently audits whether AI agents actually do what they're supposed to, not just compliance/security checks. Drops the agent into a simulated business, sends a day's worth of requests (including role-violating ones), graded by a judge model from a different provider than the agent. Default run = 10 inspections (61 with --full-run); A-F grade across 5 pillars (fabrication, manipulation, deception, unpredictability, opacity); 3 mandatory checks cap the grade at D if failed. JSON/Markdown reports, --min-score flag for CI gating, no-API-key demo mode, plugins for Claude Code and Codex. Apache 2.0, ~42.5k stars/1.8k forks.
   Why it matters: Gives teams deploying autonomous agents a concrete, CI-integrable way to catch deceptive or out-of-scope behavior before production.
   Status: ✅ verified

4. **kornia/kornia — geometric computer vision library** — https://github.com/kornia/kornia
   Source: GitHub Trending
   Summary: Apache-2.0 PyTorch-based "Geometric Computer Vision Library for Spatial AI," offering differentiable image processing and geometry operations. 500+ to 1,200+ operators (repo's own page is internally inconsistent on the count) spanning filters, augmentation, feature detection/matching, camera calibration, stereo, and pose estimation; runs on-device, supports torch.compile and ONNX export. Reports GPU speedups (10-70x, 100x+ compiled) over CPU-based vision libraries; known half-precision CPU failures, no CUDA/MPS half-precision CI coverage. Pip installable, ~11.8k stars, 4,741 commits.
   Why it matters: Gives developers building robotics, AR/VR, or spatial-AI pipelines a mature, differentiable, GPU-native alternative to classical CV libraries when gradients through vision operations are needed.
   Status: ✅ verified

5. **oraios/serena — MCP toolkit for semantic coding assistance** — https://github.com/oraios/serena
   Source: GitHub Trending
   Summary: MCP toolkit giving AI coding agents symbol-level, IDE-like code retrieval, editing, refactoring, and debugging via LSP (40+ languages), instead of plain-text line search. Optional paid JetBrains plugin adds interactive debugging and some refactors. Install via `uv tool install -p 3.13 serena-agent` + `serena init`. Works with Claude Code, Codex, VS Code, Cursor, JetBrains, Claude Desktop, OpenWebUI, plus cross-session memory. GPL-3.0-or-later (SolidLSP component MIT), ~31k stars, 3,620 commits; recent v2 adds a REPL-based agent interface.
   Why it matters: Lets developers plug semantic, codebase-aware navigation and editing into any MCP-compatible AI coding assistant, reducing token waste and errors from agents grepping and guessing at code structure.
   Status: ✅ verified
