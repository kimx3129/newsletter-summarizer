## 5. [scriptc — TypeScript-to-Native Compiler](https://github.com/vercel-labs/scriptc)
Source: github.com
Status: ✅ verified

scriptc is an AOT compiler that turns TypeScript/JavaScript into typed IR, C, LLVM IR, native assembly/objects, executables, or WebAssembly, targeting macOS, Linux, Windows, and WASI (via Zig). Static compilation requires no bundled JS runtime; a `--dynamic` flag embeds quickjs-ng as a fallback for npm packages or `any`-typed code that can't be statically compiled.

Why it matters: Unlike Bun/Deno's `compile`, which bundle a full JS engine into the binary, scriptc's static-first approach can produce native binaries without a bundled runtime, appealing to teams wanting smaller, more predictable native TS builds.
