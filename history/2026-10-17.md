## 2. Cursor plugins — official plugin spec/collection
- Source: GitHub (Cursor)
- URL: https://github.com/cursor/plugins
- Status: ✅ verified (corrected)
- Summary: Official Cursor plugins spec + marketplace repo (MIT-licensed), ~11.9k stars, 574 commits, 206 open PRs, 68 open issues, ~96 plugins across 4 categories (Utilities, Developer Tools, Productivity, Integrations). A plugin is a directory with a .cursor-plugin/plugin.json manifest bundling SKILL.md files, .mdc rules, and MCP server definitions; marketplace.json lists them all. Notable plugins: GitHub, Playwright, Orchestrate (parallel cloud agents), Google Workspace, Cursor Team Kit, Ralph Loop. No versioned releases yet.
- Why it matters: Standardizes how third-party tools/integrations plug into Cursor, likely accelerating ecosystem growth around the editor.
