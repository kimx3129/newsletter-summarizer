**2. huggingface/transformers**
URL: https://github.com/huggingface/transformers
Source: GitHub Trending
1. Hugging Face's `transformers` library is a shared "model-definition framework" for SOTA ML models across text, vision, audio, video, and multimodal tasks.
2. ~169.2k stars, 35.2k forks, ~24,900 commits; needs Python 3.11+ and PyTorch 2.6+; links to 1M+ pretrained checkpoints on the Hub.

Why it matters: De facto standard interchange format for ML models; v5 migration affects most developers/researchers using open models.

**3. p-e-w/heretic**
URL: https://github.com/p-e-w/heretic
Source: GitHub Trending
1. Heretic is an open-source, training-free Python tool (`pip install -U heretic-llm`) that reduces refusals/sycophancy/"slop" without retraining.
2. Uses an Optuna TPE optimizer to tune steering params (default "Arbitrary-Rank Ablation," classic abliteration also offered); Qwen3-4B-Instruct-2507 takes ~30-40 min on an RTX 3090.
3. ~42k stars; includes "Heretic Grimoire" reproducibility manifests; thousands of models built with it published on Hugging Face.
Why it matters: Lowers the technical bar for stripping safety guardrails from open-weight models — relevant to AI safety researchers, model providers, and policymakers.

**4. astral-sh/uv**
URL: https://github.com/astral-sh/uv
Source: GitHub Trending

**5. anthropics/claude-code-security-review**
URL: https://github.com/anthropics/claude-code-security-review
Source: GitHub Trending
1. A GitHub Action that uses Claude to semantically analyze PR diffs for security vulnerabilities and post findings as PR comments.
2. Covers injection, auth/authorization flaws, hardcoded secrets, crypto weaknesses, deserialization/eval injection, XSS; includes false-positive filtering; default model claude-opus-4-1-20250805.
3. ~7.0k stars, 800 forks, MIT-licensed; explicitly warns it is not hardened against prompt injection, recommending it only run on trusted PRs with maintainer approval required for external contributors.
Why it matters: Easy AI-driven security review for CI pipelines, but the prompt-injection caveat is a real operational risk teams must account for.

3. Supports Claude Code, Cursor, Codex, OpenCode, GitHub Copilot CLI; ~59.7k stars, 5.4k forks, Apache-2.0.
Why it matters: Addresses a core agentic-AI bottleneck — giving agents structured access to full-featured software.
