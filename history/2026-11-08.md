## 5. [ranxianglei/billion-context — context-compression plugin for long AI sessions](https://github.com/ranxianglei/billion-context) — ✅ verified (corrected)

## 6. [vercel-labs/agent-browser — browser automation CLI for AI agents](https://github.com/vercel-labs/agent-browser) — ✅ verified
Source: GitHub (vercel-labs/agent-browser)

Native Rust CLI from Vercel Labs giving AI agents browser control one command at a time via "snapshot" returning compact text with element refs. Runs through per-session background daemon over CDP, supports CSS/text/XPath/semantic selectors, fails on hidden/disabled/covered targets, ships MCP server mode; ~46.8k stars, 3.2k forks, Apache-2.0.

Why it matters: Lighter-weight agent-native alternative to Playwright/Puppeteer with built-in MCP support.
