**Source:** GitHub (Google)
Python library for extracting structured information from unstructured text using LLMs, with precise source grounding and interactive visualization.
Confirmed at 38.9k stars / 2.7k forks.
**Why it matters:** Source-grounded extraction addresses a key LLM reliability gap (hallucinated extractions) and could become a go-to building block for RAG/data-pipeline use cases.
