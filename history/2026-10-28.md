## 3. [NVIDIA/auto-ontology](https://github.com/NVIDIA/auto-ontology)
**Source:** GitHub Trending
**Status:** ✅ verified

1. Apache-2.0 open-source framework providing a semantic, graph-based context layer for AI agents querying enterprise data.
2. Generates ontologies from metadata, reconciles inconsistent definitions across systems, translates natural language to SQL against Databricks/Postgres/Snowflake/DuckDB, and serves that context via MCP, CLI, and API.
3. 342 stars; not accepting external contributions.

**Why it matters:** Database credentials entered through the UI are stored in plaintext in Postgres unless HashiCorp Vault is explicitly configured — a real security caveat for anyone deploying this against production enterprise databases.
