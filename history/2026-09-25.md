### 2. [vectorize-io/hindsight](https://github.com/vectorize-io/hindsight)
**Source:** GitHub (Vectorize)
Hindsight is an open-source agent memory system built around retain/recall/reflect primitives, now at 27.8k stars under the MIT license.
It claims state-of-the-art results on the LongMemEval benchmark for long-term conversational memory.
The project targets agents that need durable, structured context across long-running interactions.
**Why it matters:** A permissively licensed, benchmark-backed memory layer fills a real gap for agents needing long-term context.
