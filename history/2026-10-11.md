## 1. TRELLIS.2 — verified (corrected)
https://github.com/microsoft/TRELLIS.2
Source: GitHub (microsoft)
Microsoft open-sourced TRELLIS.2, a 4B-parameter image-to-3D generative model built on a new "O-Voxel" sparse voxel representation plus a sparse 3D VAE and DiT generator. Outputs textured meshes with PBR materials at resolutions 512³-1536³; converting a textured mesh to O-Voxel takes under 10s on CPU, while the reverse (O-Voxel to textured mesh) takes under 100ms on CUDA; full generation ~3s-60s on H100 depending on resolution; code, 4B checkpoints, HF demo released under MIT. ~11.8k stars/1.4k forks; requires Linux + 24GB+ NVIDIA VRAM; no published benchmarks vs original TRELLIS or competitors.
Why it matters: Fast, open-weight, MIT-licensed 3D asset generator from Microsoft lowers barrier for game studios/3D pipeline developers.

## 2. diagram-design — verified
https://github.com/cathrynlavery/diagram-design
Source: GitHub (cathrynlavery)

Why it matters: Drop-in way to produce polished, on-brand diagrams without manual design tools.

## 6. context-mode — verified
https://github.com/mksglu/context-mode
Source: GitHub (mksglu)
MCP server + hook system to cut raw tool output filling an AI coding agent's context window. Sandboxes tool execution so only stdout returns (315KB→5.4KB reduction example); indexes content in SQLite FTS5 for BM25-ranked retrieval; persists session state via hooks for recovery after compaction. Supports 17+ agent hosts. Elastic License 2.0.
Why it matters: Addresses concrete reliability gap for developers running multi-hour agentic sessions.
