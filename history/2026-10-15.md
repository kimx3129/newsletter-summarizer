**3. [agent-toolkit-for-aws](https://github.com/aws/agent-toolkit-for-aws)**
Source: GitHub Trending
AWS's official MCP servers/skills/plugins for agents building on AWS. 5 plugins (aws-core, aws-agents, aws-data-analytics, aws-agents-for-devsecops, aws-startup-advisor), an MCP server exposing 300+ AWS services via one endpoint, and IAM condition keys scoping agent vs. human permissions. 2.9k stars, Apache-2.0.
Why it matters: Positioned as successor to the community AWS Labs MCP servers, adding CloudWatch/CloudTrail audit logging; supports Claude Code, Codex, Cursor, Kiro, and fx.

**4. [claude-plugins-official](https://github.com/anthropics/claude-plugins-official)**
Source: GitHub Trending
Anthropic's official curated Claude Code plugin directory/marketplace, installed via `/plugin install {plugin-name}@claude-plugins-official`. Separates Anthropic's own plugins from vetted third-party plugins. 38.1k stars, 4.3k forks, Apache-2.0.
Why it matters: Anthropic explicitly disclaims control over third-party plugin behavior — users must vet plugins themselves.

**5. [CLI-Anything](https://github.com/HKUDS/CLI-Anything)**
Source: GitHub Trending
HKUDS's open-source generator wraps GUI apps in agent-friendly CLIs via a 7-phase pipeline (Analyze, Design, Implement, Plan Tests, Write Tests, Document, Publish), with Click-based CLIs offering JSON output. Includes a CLI-Hub package manager and prebuilt harnesses for GIMP, Blender, LibreOffice, and Godot. 52.5k stars, Apache-2.0.
Why it matters: Could remove a major bottleneck for agentic automation of mainstream GUI software; supports Claude Code, Cursor, Codex.

**6. [scientific-agent-skills](https://github.com/K-Dense-AI/scientific-agent-skills)**
Source: GitHub Trending
K-Dense-AI's library of 177 skill packages for scientific research (bioinformatics, cheminformatics, proteomics, clinical research, imaging, materials science), citing 100+ databases. Install via `npx skills add`. 49.3k stars, MIT, v2.72.0. Formerly "Claude Scientific Skills."
Why it matters: Lowers the barrier for researchers to turn general coding agents into domain-competent scientific assistants.

**7. [heretic](https://github.com/p-e-w/heretic)**
Source: GitHub Trending
p-e-w's tool automatically strips refusal/safety-alignment behavior ("abliteration") from open-weight LLMs via an Optuna TPE optimizer. On gemma-3-12b-it, cuts refusals from 97/100 to 3/100 while holding KL divergence to 0.16. 35.3k stars, AGPL-3.0.
Why it matters: Makes bypassing model safety guardrails trivial and widely distributable, raising misuse risk.

**8. [PentAGI](https://github.com/vxcontrol/pentagi)**
Source: GitHub Trending
vxcontrol's self-hostable, fully autonomous multi-agent system for authorized penetration testing. Go backend, React frontend, GraphQL API, supports 10+ model providers including Anthropic and OpenAI. 29.4k stars, 4.4k forks, MIT.
Why it matters: Lowers the skill floor for running autonomous offensive-security operations — benefits authorized teams but also lowers the bar for misuse.
