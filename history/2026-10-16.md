## 2. OpenViking — unified context DB for AI agents
- Source: GitHub (Volcengine/ByteDance)
- URL: https://github.com/volcengine/OpenViking
- Status: ✅ verified
- Summary: Volcengine (ByteDance's cloud arm) released an open-source context database unifying an AI agent's RAG/knowledge, session memory, and skills into a single virtual filesystem (viking:// paths, ls/tree/read/write/grep). Reports 80-83% accuracy on the LoCoMo memory benchmark vs 24-57% for native agent memory; tau2-bench task-success gains of +6.87pp (retail)/+11.87pp (airline). ~40k GitHub stars, 3.2k forks, AGPLv3 core.
- Why it matters: Developers building long-running AI agents get a ready-made, benchmarked memory/RAG/skills layer instead of bespoke context-management infrastructure.

## 3. Trail of Bits' Claude Code skills for security research/audit
- Source: GitHub (Trail of Bits)
- URL: https://github.com/trailofbits/skills
- Status: ✅ verified
- Summary: Security firm Trail of Bits published a Claude Code/Codex-compatible plugin marketplace of skills for security code review, testing, and auditing — covering smart contracts, C/C++/Rust auditing, CodeQL/Semgrep static analysis, supply-chain auditing, timing side-channel analysis, and more. The constant-time-analysis skill already found a real timing side-channel in ML-DSA signing, reported via PR to RustCrypto. CC-BY-SA-4.0, ~7.6k stars, 651 forks.
- Why it matters: Security researchers get a vetted, Trail of Bits-authored toolkit turning Claude Code into a specialized static-analysis/auditing assistant.

## 4. sglang-omni — SGLang serving framework for audio + multimodal models
- Source: GitHub (SGLang project)
- URL: https://github.com/sgl-project/sglang-omni
- Status: ✅ verified
- Summary: The SGLang project released a multi-stage serving runtime purpose-built for omni, speech, and TTS/ASR models, splitting generation across pipeline stages with workload-specific scheduling. Exposes an OpenAI-compatible API (chat, audio/speech, transcription); supports Qwen3-Omni, Higgs Audio v3, Qwen3-ASR/TTS, MiniMax Music 3, and others. Primary NVIDIA CUDA backend, experimental Apple Silicon/Intel XPU support.
- Why it matters: Teams deploying speech/multimodal models get a dedicated, pipeline-aware serving layer instead of forcing audio workloads through text-oriented LLM servers.
