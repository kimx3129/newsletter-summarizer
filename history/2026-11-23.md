## 1. [PaperOrchestra](https://github.com/google-research/paper-orchestra)
Source: GitHub (Google Research)
- Google Research published PaperOrchestra, an Apache-2.0 multi-agent framework turning raw research materials into submission-ready LaTeX manuscripts.
- Specialized agents handle outline/lit-review/writing/refinement/plotting stages, via Python CLI or bash script, requiring Python 3.11 + Semantic Scholar + Gemini/Vertex AI or OpenAI keys; Streamlit demo included.
- Accompanies arXiv preprint 2604.05018 (2026) by Yiwen Song, Yale Song, Tomas Pfister, Jinsung Yoon of Google Cloud AI Research; dataset not yet released; explicitly not an officially supported Google product.

Why it matters: Automates mechanical parts of paper writing, raises questions about AI-authored content in peer review.

Status: ✅ verified

## 2. [OpenVINO](https://github.com/openvinotoolkit/openvino)
Source: GitHub (Intel)
- Intel's actively maintained Apache-2.0 toolkit for optimizing/deploying inference across CPU(x86/ARM)/GPU/NPU.
- Supports PyTorch/TensorFlow/ONNX/Keras/PaddlePaddle/JAX via Optimum Intel; C++/Python/C/NodeJS APIs incl. GenAI pipeline API; integrates NNCF, OpenVINO Model Server, vLLM, LangChain, ONNX Runtime; install via pip.
- ~24,000 commits, 12.1k stars, 3.7k forks, 419 open issues, 790 open PRs.

Why it matters: Single actively-supported optimization path for Intel CPU/GPU/NPU deployment, avoiding Nvidia lock-in.

Status: ✅ verified

## 3. [agents (wshobson)](https://github.com/wshobson/agents)
Source: GitHub
- MIT-licensed collection of plugins/agents/skills/commands, written in Claude Code Markdown plugin format, adapted to other tools.
- Catalogs 93 plugins, 199 agents, 185 skills, 103 commands; supports Claude Code, Codex CLI, Cursor, OpenCode, Antigravity CLI, Copilot, Pi; ~42.8k stars, 4.5k forks.
- Paid "Verified" tier from Major7 Apps; Pensyve memory integration lost hosted cloud endpoints Oct 1, 2026.

Why it matters: One shared agent/skill set across multiple AI coding assistants; commercial "Verified" layer signals monetization pressure.

Status: ✅ verified

## 4. [treg](https://github.com/superdesigndev/treg)
Source: GitHub
- "OpenRouter for agent tools" — registry/proxy giving agents one base URL/token for many paid tools (SEO, enrichment, scraping, ads, image/video gen).
- Holds upstream accounts, meters usage per-call from prepaid balance; private tools never metered; audit record per call via /call/ endpoint; CLI, web dashboard, Claude Code plugin, Arena-style comparisons.
- Self-hostable (FastAPI/SQLModel, SQLite/Postgres, Fernet-encrypted secrets), Apache 2.0 + anti-resale terms. ~8.7k stars, 863 forks, 52 open issues.

Why it matters: Single credential-free integration point for fragmented paid-API tool market.

Status: ✅ verified

## 5. [academic-research-skills](https://github.com/Imbad0202/academic-research-skills)
Source: GitHub
- Claude Code plugin (CC BY-NC 4.0, v3.24.4) implementing human-in-the-loop research→write→review→revise→finalize pipeline.
- Bundles 5 skills: 13-agent Deep Research (8 modes), 12-agent Academic Paper writer (11 modes, LaTeX/APA), 7-agent simulated peer reviewer (flagged NOT_CALIBRATED), 10-stage pipeline orchestrator, SR-Screener. ~$3-7 cost per 15k-word paper.
- Pauses for user confirmation at every stage; frames AI as copilot not author; does not verify underlying experiments were performed.

Why it matters: Packages AI-assisted academic writing/peer review with guardrails and disclosed limitations.

Status: ✅ verified
