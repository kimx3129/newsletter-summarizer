1. **[colibri (JustVugg/colibri)](https://github.com/JustVugg/colibri)** — GitHub
   Pure-C, dependency-free inference engine running MoE models up to 2.8T params (e.g. Kimi K3) via disk/RAM/VRAM memory hierarchy streaming. Supports 9 model families; 5.8-6.8 tok/s decode on 6xRTX5090 (744B GLM-5.2) down to 0.05-0.1 tok/s on a minimal 25GB dev box. Apache 2.0, 34.9k stars, 3.7k forks.
   *Why it matters:* Makes running frontier-scale MoE models feasible on consumer hardware, though throughput figures are self-reported.
   Status: ✅ verified (corrected)

2. **[open-code-review (alibaba/open-code-review)](https://github.com/alibaba/open-code-review)** — GitHub
   Alibaba's AI-powered CLI for git-diff code review, combining LLM analysis with rule-based checks (NPE, thread-safety, XSS, SQLi); integrates with Claude Code, Codex, Cursor, GitHub Actions, GitLab CI, Gerrit. Benchmarked on 50 repos/200 PRs/10 languages, claims higher precision/F1 than general agents at ~1/9 token cost. Apache-2.0, 31.5k stars, 2.2k forks.
   *Why it matters:* Cheaper, more precise alternative to general-purpose agentic code review (benchmark is self-reported by Alibaba).
   Status: ✅ verified
