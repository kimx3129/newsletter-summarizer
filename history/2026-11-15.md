## ✅ Verified (5)

### 1. [openworker](https://github.com/andrewyng/openworker)
**Source:** GitHub (andrewyng)
Andrew Ng's new open-source project: MIT-licensed desktop "AI coworker" app + "Harness SDK" (TypeScript SDK + Rust engine, Python backend via aisuite).
Supports cloud models (OpenAI, Anthropic, Gemini, OpenRouter) and local models (Ollama, LM Studio, llama.cpp, vLLM).
Default-on approvals, audit trail, sandboxing (NVIDIA OpenShell/OS sandboxes), MCP integrations (GitHub/Slack/email). ~19.2k stars, 2.7k forks, 1,184 commits.
**Why it matters:** A notable "safe autonomous agent" entrant from a high-profile AI figure, with real approval/audit/sandboxing controls.

### 2. [Univer](https://github.com/dream-num/univer)
**Source:** GitHub (dream-num)
Apache-2.0 Office SDK from DreamNum for spreadsheet/doc editing + collaboration. Open-source Web SDK + commercial Server/AI SDK.
AI SDK adds isolated "Worktree" drafts for agent edits before human review; integrations with CLI, DeepSeek Harness, WorkBuddy, OpenClaw.
~24.5k stars, 2.2k forks, 6,046 commits.
**Why it matters:** Practical infrastructure letting AI agents safely edit office documents in isolated drafts before merge.

### 3. [ag-ui](https://github.com/ag-ui-protocol/ag-ui)
**Source:** GitHub (ag-ui-protocol)
MIT-licensed, event-based, transport-agnostic protocol (SSE/WebSockets/webhooks) connecting AI agent backends to frontends — ~16 event types for streaming chat, state sync, generative UI, human-in-the-loop.
Grew out of CopilotKit+LangChain+CrewAI; integrations with Microsoft Agent Framework, Google ADK, AWS Strands, Mastra.
~17.4k stars, 1.7k forks.
**Why it matters:** Positioned as the "agent-to-UI" standardization layer alongside MCP (tools) and A2A (agent-to-agent).

### 4. [TensorFold](https://github.com/ashhart/TensorFold) — corrected
**Source:** GitHub (ashhart)
Apache-2.0, Zig-based LLM inference engine, no Python/MLX needed, OpenAI/Responses/Anthropic-compatible APIs. Confirmed backends: Metal + CUDA (sm_80-sm_121); HIP for exactly one AMD GPU (R9700, OCR model only).
Features: context compaction, "Cortheon mode", experimental "Living Weights". No published throughput benchmarks. ~2.2k stars, 8,276 commits, v1.2.9.
**Correction:** Vulkan is in the project tagline but NOT actually supported per the README — this headline claim is unsubstantiated.
**Why it matters:** Fast-growing dependency-light inference engine, but readers should discount the "Vulkan" claim.

### 5. [VieNeu-TTS](https://github.com/pnnbao97/VieNeu-TTS) — corrected
**Source:** GitHub (pnnbao97)
Apache-2.0 Vietnamese TTS (v3 Turbo, MOSS-Audio-Tokenizer-Nano codec). Instant voice cloning from 3-8s clip, 48kHz output, 25 preset voices, batched gen up to 32, real-time streaming, OpenAI-compatible /v1/audio/speech endpoint.
Self-reported/unaudited: ~115ms first-audio latency (RTX 3060), ~1.6x-2.9x real-time on 12th-gen i5 CPU (corrected from an earlier "~2x" paraphrase). v4 (best quality) is proprietary/paid via vieneu.io; v3 Nano (48M params) targets weak CPUs/edge.
~3.3k stars, 1.0k forks.
**Why it matters:** Notable fully-open TTS stack for a historically underserved language, but benchmark numbers are vendor-self-reported, not independently audited.
