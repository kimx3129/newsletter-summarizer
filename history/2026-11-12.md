## 1. [Anthropic IPO roadshow launch](https://www.anthropic.com/news/roadshow-launch) ✅ verified (corrected)
Source: anthropic.com
Anthropic announced on Nov 10, 2026 that it launched the roadshow for a proposed IPO of its Class A common stock, having filed a (not-yet-effective) SEC registration statement. The offering totals 825,000,000 shares (801,351,354 from Anthropic, 23,648,646 from existing stockholders) at $70.00–$78.00/share, targeting the Nasdaq Global Select Market under ticker "ANT." Goldman Sachs and Morgan Stanley are distributing the preliminary prospectus, with a 30-day option for underwriters to buy 123,750,000 additional shares.
Why it matters: One of the largest AI-sector IPOs to date; the price range gives the market its first concrete read on Anthropic's implied valuation.

## 2. [openai/codex-security](https://github.com/openai/codex-security) ✅ verified
Source: github.com
CLI + TypeScript SDK (ships as npm package `@openai/codex-security`, CLI command `codex-security`/`cs`) for finding, validating, and fixing security vulnerabilities in code; runs as a plugin inside OpenAI's Codex agent ecosystem; exports SARIF/JSON/CSV. ~11,700 stars.
Why it matters: Developers get an AI vulnerability scanner integrated into the same toolchain as Codex, reducing reliance on separate SAST tools.

## 3. [browser-use/browser-use](https://github.com/browser-use/browser-use) ✅ verified
Source: github.com
Open-source, MIT-licensed Python library for building AI browser agents (drives real browsers via CDP), paired with a hosted "Browser Use Cloud" service offering stealth browsers, CAPTCHA solving, residential proxies, and an agent API. ~120,700 stars.
Why it matters: Mature, widely-adopted foundation for shipping browser-automation agents instead of building low-level browser control from scratch.

## 4. [sgl-project/sglang-omni](https://github.com/sgl-project/sglang-omni) ✅ verified
Source: github.com
New serving runtime built on the SGLang ecosystem, tagline "High Performance Serving Runtime For Interactive Super Intelligence System" — supports full-duplex realtime conversation, streaming output, and interruption handling. ~1,760 stars.
Why it matters: Gives infra teams running latency-sensitive agent systems another specialized serving-runtime option alongside vLLM/TensorRT-LLM.

## 5. [shadcn/improve](https://github.com/shadcn/improve) ✅ verified
Source: github.com
New tool from the creator of shadcn/ui where a capable AI model audits a codebase and writes an execution plan — "never implements anything itself, the plan is the product" — for cheaper models to carry out. ~10,850 stars, fastest-growing in today's batch.
Why it matters: Offers a cost-control pattern for AI-assisted coding — expensive models for planning/auditing, cheap models for execution.

## 6. [ZhuLinsen/daily_stock_analysis](https://github.com/ZhuLinsen/daily_stock_analysis) ✅ verified
Source: github.com
LLM-powered multi-market (A-shares, HK, US, Japan, Korea, Taiwan) stock analysis tool with a decision dashboard, multi-channel notifications (WeChat Work/Feishu/Telegram/Discord/Slack/email), and scheduled runs via GitHub Actions/Docker/local. ~70,200 stars.
Why it matters: Ready-made template for automated, LLM-driven market monitoring — though the unusually high star count for a single-contributor repo and its trading-relevant outputs warrant reader skepticism.

## 7. [experientiallabs/experiential](https://github.com/experientiallabs/experiential) ✅ verified
Source: github.com
Open-source, self-hosted, zero-markup BYOK gateway routing requests across 1,000+ AI models. ~16,570 stars.
Why it matters: Lets developers consolidate access to many model providers behind a self-hosted gateway without per-token markup fees charged by commercial routing services.
