## ✅ Verified (4)

### 1. [paper-orchestra](https://github.com/google-research/paper-orchestra)
**Source:** GitHub (google-research)
Google Cloud AI Research released paper-orchestra, a multi-agent framework that turns raw ideas and experimental logs into submission-ready LaTeX manuscripts via agents for outlining, literature review, section writing, refinement, and plotting.
Documented in arXiv preprint 2604.05018, Apache-2.0, 1.5k stars, 237 forks, 8 commits.
**Why it matters:** A credible attempt at automating academic paper writing end-to-end from Google's own research org (though marked "not an officially supported Google product").

### 2. [Vibe-Trading](https://github.com/HKUDS/Vibe-Trading)
**Source:** GitHub (HKUDS)
Personal AI trading agent offering 30 preset research teams, a Quant Lab benchmarking 478 alphas, 19 broker connectors, and 28 market-data sources, accessible via CLI, web app, HTTP API, or MCP.
38.4k stars, MIT-licensed.
**Why it matters:** Packages a lot of trading infrastructure behind one agent interface, but the README itself flags live-trading support as "experimental and not verified by us against a real broker account" — a real-money caution worth keeping.

### 3. [SkillEvaluator](https://github.com/NVIDIA/SkillEvaluator)
**Source:** GitHub (NVIDIA)
NVIDIA's three-tier framework for evaluating AI agent skills/plugins: safety/structure validation, overlap/deduplication detection, and sandboxed live A/B evaluation, plus a deterministic quality-check mode and rubric-eval scoring via NVIDIA Build API.
Apache-2.0, "Experimental," 2.7k stars, 627 commits, arXiv 2608.20614.
**Why it matters:** Confirmed distinct from NVIDIA/SkillSpector (a separate pinned dependency it uses for security scanning, not a rename) — useful for anyone building/distributing agent skills as skill marketplaces proliferate.

### 4. [claude-code-templates](https://github.com/davila7/claude-code-templates)
**Source:** GitHub (davila7)
An open-source registry and CLI for installing Claude Code agents, commands, skills, hooks, MCPs, and settings — cataloging 918 skills, 422 agents, 288 commands, 119 MCPs, 80 settings, 63 hooks via a companion site aitmpl.com.
33.9k stars, 4.0k forks, 2,136 commits, MIT.
**Why it matters:** A de facto package manager for the Claude Code ecosystem; its own PR pipeline is validated by Claude Code's plugin validator and NVIDIA's SkillSpector.
