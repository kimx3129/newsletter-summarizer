# 📰 Tech/AI Daily Digest — 2026-10-08

⚠️ Note: Major source outages today (HN, arXiv, Reddit, OpenAI, DeepMind, Meta, Hugging Face, TechCrunch, The Verge, Ars Technica all unreachable) — only GitHub Trending and Anthropic's blog were reachable, so today's digest is smaller and skews toward GitHub dev-tooling repos.

## 1. ✅ verified — vLLM
https://github.com/vllm-project/vllm
Open-source, high-throughput, memory-efficient LLM inference/serving engine (Apache-2.0). ~93.3k stars, ~23.1k forks, 22,630 commits, 2,000+ contributors. Supports 200+ Hugging Face model architectures; implements PagedAttention and continuous batching for high-throughput serving.
Why it matters: De facto standard open-source engine for serving open LLMs at scale.

## 2. ✅ verified — olmOCR
https://github.com/allenai/olmocr
AllenAI's Apache-2.0 toolkit converts PDFs/scanned images into clean text for LLM training datasets. ~19.7k stars, 2,126 commits. v0.4.0 scores 82.4±1.1 on olmOCR-Bench; claims <$200 per million pages processing cost.
Why it matters: Strong open-source alternative to closed OCR APIs — competitive accuracy, very low per-page cost for large-scale document digitization.

## 3. ✅ verified — MarkItDown
https://github.com/microsoft/markitdown
Microsoft's MIT-licensed tool converts files (Office docs, PDFs, images, etc.) to Markdown for LLM pipelines. ~189k stars, ~14k forks.
Why it matters: Widely-used preprocessing step for feeding mixed-format documents into LLM/RAG pipelines.

## 4. ✅ verified — RAD Debugger
https://github.com/EpicGames/raddebugger
Epic Games' MIT-licensed native, multi-process graphical debugger. ~7.9k stars, 4,686 commits. Alpha stage; currently Windows x64 only (Linux/DWARF support planned).
Why it matters: Serious, well-funded alternative to existing native debuggers (WinDbg/gdb) from a major game studio.

## 5. ✅ verified — Cloudflare Security Audit Skill
https://github.com/cloudflare/security-audit-skill
Cloudflare's agent skill turns a coding agent into a multi-phase security auditor with machine-readable findings and independent verification of each finding. ~26.0k stars, only 14 commits on main.
Why it matters: Reusable template for AI-driven security review with built-in false-positive control.

## 6. ✅ verified — Uber ADR
https://github.com/uber/ADR
Uber's Apache-2.0 open-source framework for enterprise AI agent security, observability, and threat detection. ~1.9k stars, 196 forks, 115 commits. Accompanying paper accepted to MLSys 2026.
Why it matters: Research-backed, production-origin tooling for detecting attacks against AI coding/support agents at enterprise scale.

## 7. ✅ verified — Cua
https://github.com/trycua/cua
Open-source "computer use" framework giving AI agents cross-OS control of native apps/browsers, plus benchmarks. ~28.7k stars, ~2.0k forks, 5,274 commits. Mostly MIT; some components (Cua Spaces) under FSL-1.1-MIT.
Why it matters: Open, cross-platform alternative to closed computer-use APIs for building/benchmarking desktop-operating agents.

## 8. ⚠️ unverified — Agent Skills (Addy Osmani)

MIT-licensed collection of 25 "production-grade" engineering skills for AI coding agents (Claude Code, Cursor, Codex, etc.), organized by dev lifecycle stage.

Star count is accurately read from GitHub, but organic legitimacy (vs. bot/campaign-inflated stars) could not be independently confirmed (GitHub API access was blocked).
