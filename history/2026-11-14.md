## ✅ Verified (3)

### 1. [headroom](https://github.com/headroomlabs-ai/headroom)
**Source:** GitHub (headroomlabs-ai)
Compresses tool outputs, logs, and RAG chunks before they reach the LLM via SmartCrusher, CodeCompressor, and Kompress-v2-base.
Reports 21–57% input-token reduction, 90%+ on repetitive JSON/logs.
79.6k GitHub stars.
**Why it matters:** could meaningfully cut inference costs and context pressure for agentic tool-use pipelines.

### 2. [Alibaba open-code-review](https://github.com/alibaba/open-code-review)
**Source:** GitHub (alibaba)
Hybrid deterministic+LLM code review CLI (`ocr review` / `ocr scan`) with built-in NPE/thread-safety/XSS/SQLi rules and CI integrations.
Self-reported AACR-Bench claims higher precision/F1 than Claude Code using ~1/9th the tokens (lower recall tradeoff — benchmark is self-reported by Alibaba, unverified claim).
50.6k GitHub stars.
**Why it matters:** token-cheaper, precision-focused alternative to general coding-agent review, though the benchmark numbers are self-reported.

### 3. [chrome-devtools-mcp](https://github.com/ChromeDevTools/chrome-devtools-mcp)
**Source:** GitHub (ChromeDevTools)
Official MCP server giving coding agents control and visibility into live Chrome via DevTools: performance tracing, network/console/screenshot inspection, Puppeteer automation, bundled debugging skills.
55.4k GitHub stars.
**Why it matters:** standardized, officially-backed way for agents to debug/performance-test real web pages instead of relying on screenshots. Note: the README warns it exposes browser content to MCP clients — avoid using it on sessions with sensitive/authenticated data.
