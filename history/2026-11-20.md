## Verified stories (6)

1. **[superpowers](https://github.com/obra/superpowers)** — GitHub (obra)
   Agentic skills framework and software development methodology for coding agents (Claude Code, Codex, Cursor, Gemini CLI). Gives agents composable skills for brainstorming, TDD, debugging, code review, and git-worktree-based subagent task execution.
   Designed as "mandatory workflows, not suggestions." ~322k stars, #1 trending repo today (+2,028).
   Why it matters: Offers a ready-made, enforceable process to curb coding agents' tendency to code before clarifying requirements or skip testing/verification.
   Status: ✅ verified

2. **[markitdown](https://github.com/microsoft/markitdown)** — GitHub (Microsoft)
   Python tool converting files/office docs (PDF, Word, Excel, PowerPoint, images w/ OCR, audio, HTML, YouTube, etc.) to Markdown for LLM ingestion, with optional Azure Document Intelligence integration.
   ~197k stars, #1 trending Python repo.
   Why it matters: Widely-adopted, Microsoft-maintained building block for RAG/LLM ingestion pipelines needing structure-preserving text extraction.
   Status: ✅ verified

3. **[firecrawl](https://github.com/firecrawl/firecrawl)** — GitHub
   Web search/scrape/data API built for AI agents, turning websites into LLM-ready markdown/JSON; self-hosted or cloud, with MCP server integration for Claude Code/Desktop, Cursor, Windsurf, Gemini CLI, Codex.
   ~204k stars (+825 today).
   Why it matters: A single production-grade API for the search-and-scrape layer of AI agents instead of stitching together separate tools.
   Status: ✅ verified

4. **[spec-kit](https://github.com/github/spec-kit)** — GitHub
   GitHub's own toolkit for Spec-Driven Development: specify → plan → tasks → implement → converge, run as skills inside an AI coding agent's chat.
   ~150.7k stars.
   Why it matters: Formalizes a reusable, agent-agnostic methodology for turning specs into working code, useful for teams wanting predictable/auditable AI-assisted development.
   Status: ✅ verified

5. **[torchtitan](https://github.com/pytorch/torchtitan)** — GitHub (PyTorch)
   PyTorch-native platform for pretraining/post-training generative models at scale; composable parallelism (FSDP2, tensor/pipeline/context/expert) without model rewrites; supports Llama 3, Qwen3, DeepSeek V3, gpt-oss, Kimi, FLUX; includes TitanRL sharing code with vLLM.
   ~5.9k stars.
   Why it matters: Officially PyTorch-maintained path from pretraining through SFT to RL across multiple open model families, cutting custom distributed-training glue code.
   Status: ✅ verified

6. **[cli-agent-orchestrator](https://github.com/awslabs/cli-agent-orchestrator)** — GitHub (AWS Labs)
   Apache-2.0 tool for multi-agent orchestration of AI coding CLIs (Claude Code, Kiro, Codex, Copilot CLI, Cursor CLI) in isolated tmux sessions, with a supervisor-agent/worker-agent model, web UI, and EKS deployment option.
   ~1.6k stars.
   Why it matters: Vendor-neutral way to run/supervise multiple AI coding CLI tools side by side for benchmarking or production multi-agent coding workflows.
   Status: ✅ verified
