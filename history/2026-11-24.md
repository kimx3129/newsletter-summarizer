## 1. [minimind](https://github.com/jingyaogong/minimind)
Source: GitHub Trending
- Open-source (Apache-2.0) from-scratch LLM training pipeline (tokenizer, pretrain, SFT, LoRA, distillation, DPO/RLHF, agentic RL). Flagship dense model ~64M params (MoE variant ~198M total/64M active); ~2.3hr/~3 RMB full pretrain+SFT on single RTX 3090; ~69.4k stars/9.1k forks.
- Decoder-only transformer (8 layers, d_model 768, RMSNorm, SwiGLU, RoPE/YaRN, 6400-token vocab); OpenAI-compatible API, Streamlit WebUI, llama.cpp/vLLM/Ollama/MNN integration.
- Zero-shot C-Eval/CMMLU ~25% ("for entertainment only" per author).

Why it matters: Gives researchers and hobbyists a fully reproducible, low-cost reference pipeline for understanding the entire LLM lifecycle rather than just fine-tuning an existing checkpoint.

Status: ✅ verified

## 2. [autoclip](https://github.com/zhouxiaoka/autoclip)
Source: GitHub Trending
- MIT license, ~14.4k stars. Turns long video into short clips w/ auto subtitles/covers/titles/descriptions/hashtags as ZIP. Supports Douyin, Xiaohongshu, TikTok, Reels, YouTube Shorts, Bilibili, YouTube; up to 10 qualified clips/platform.
- Local Whisper/SenseVoice or cloud ASR; LLM-based clip selection. Local FFmpeg cutting/framing.
- Example cost ~¥0.09 for 10 clips from a 1h43m video.

Why it matters: Automates labor-intensive repurposing of long-form content into platform-ready short clips, lowering the cost of multi-platform content distribution for creators and media teams.

Status: ✅ verified

## 3. [cursor/plugins](https://github.com/cursor/plugins)
Source: GitHub Trending
- Official spec + marketplace for Cursor's plugin system. Plugin = directory w/ `.cursor-plugin/plugin.json`, discoverable via root `.cursor-plugin/marketplace.json`. Can bundle skills/, rules/ (.mdc), mcp.json.
- 17 plugins sit at the repo root (11 built by Cursor itself, incl. Thermos, Ralph Loop, Orchestrate; 6 by outside contributors) + 100+ third-party integrations (Gmail, Salesforce, HubSpot, QuickBooks).
- ~839 commits, 140 open issues, 550 PRs, ~18.8k stars; no tagged releases.

Why it matters: Establishes an extensibility standard for Cursor comparable to VS Code extensions or MCP servers, letting developers and vendors package reusable AI-agent workflows directly into the editor.

Status: ✅ verified
