1. **[BitNet](https://github.com/microsoft/BitNet)** — Source: GitHub (microsoft) — ✅ verified (corrected)
Microsoft's MIT-licensed inference framework for 1-bit (ternary) LLMs, 40.9k stars/3.8k forks.
Delivers 1.37x-5.07x speedups on ARM CPUs and 2.37x-6.17x on x86 vs full-precision models, cutting energy use 55.4%-70.0% (ARM) and 71.9%-82.2% (x86).
Flagship BitNet-b1.58-2B-4T: 2.4B params trained on 4 trillion tokens.
Why it matters: Makes running capable LLMs on commodity CPUs dramatically cheaper and more energy-efficient, without GPUs.

2. **[VoxCPM2](https://github.com/OpenBMB/VoxCPM)** — Source: GitHub (OpenBMB) — ✅ verified
Apache-2.0 2B-parameter speech model on MiniCPM-4 backbone, trained on 2M+ hours of multilingual audio across 30 languages, 39.2k stars/4.4k forks.
Outputs 48kHz audio; scores 1.84% WER (English) / 0.97% CER (Chinese) on Seed-TTS-eval.
Why it matters: Open, low-parameter TTS with strong multilingual benchmark results lowers the bar for high-quality voice synthesis outside closed APIs.

3. **[YuE2](https://github.com/multimodal-art-projection/YuE)** — Source: GitHub (multimodal-art-projection) — ✅ verified (corrected)
Music-generation model (code/docs Apache 2.0, weights CC BY-NC 4.0), 11.8k stars/1.3k forks.
YuE2-3B, best-of-8 sampling, edges out Suno v5 on WildSongBench (6.9632 vs 6.8721); single-sample score (6.7316) trails Suno v5.
Why it matters: A credible open-weight rival to Suno's closed music model under best-of-n sampling, keeping competitive pressure on commercial music-gen APIs.

4. **[AirLLM](https://github.com/lyogavin/airllm)** — Source: GitHub (lyogavin) — ✅ verified
Apache-2.0, ~37.5k stars/3.9k forks. Lets Llama 3.x 70B run at full precision on ~4GB VRAM via layer-wise offloading; claims Kimi K3 (2.8T params) runs on 3.72GB on an RTX 6000 Ada.
⚠️ unverified: README has an unresolved inconsistency — says "without quantization" while also offering optional compression, and gives the Flash-Next model's size as both 125B and ~180B in different places. Treat headline VRAM claims with some caution.
Why it matters: If accurate, lets huge models run on consumer-grade hardware — but unresolved internal numbers warrant reader caution.

5. **[google/skills](https://github.com/google/skills)** — Source: GitHub (google, verified org) — ✅ verified
Google's official (confirmed verified org) Apache-2.0 repo of Agent Skills for Google products, ~21.2k stars/1.8k forks.
Installs via `npx skills add google/skills`; covers Cloud, AI/ML, infra, databases, security domains.
Why it matters: A verified, official Google skills repo is a meaningfully different signal than a community project — worth tracking as Google's entry into the agent-skills ecosystem.

6. **[free-claude-code](https://github.com/Alishahryar1/free-claude-code)** — Source: GitHub (Alishahryar1) — ✅ verified
AGPL-3.0, ~59.1k stars/9.3k forks (confirmed via re-fetch). Independent, explicitly non-Anthropic-affiliated proxy supporting 61 model providers, claims up to 90% lower token usage via optional RTK/Headroom features.
⚠️ unverified: star count is unusually high relative to visible commit/issue activity (~1,189 commits, 225 issues) — plausibility caveat, not confirmed inflation.
Why it matters: Big claimed savings on coding-agent token costs via third-party routing — useful if real, but verify independently before relying on the savings claims.
