## 2. ✅ verified — SkillSpector
URL: https://github.com/NVIDIA/SkillSpector
Source: GitHub (NVIDIA)
Summary: NVIDIA's open-source scanner for AI agent "skills" packages detects 71 vulnerability patterns across 17 categories (prompt injection, data exfiltration, supply-chain risk, excessive agency, dangerous exec/eval, MCP-specific issues like tool poisoning). NVIDIA's own research found 26.1% of scanned skills contain vulnerabilities and 5.2% show likely malicious intent. Runs a two-stage pipeline (static analysis + optional LLM semantic analysis, with a `--no-llm` local-only mode), outputs a 0-100 risk score, supports SARIF for CI/CD, and can run as an MCP server to gate installs.
Why it matters: Gives developers a concrete way to vet third-party agent skill packages before granting them tool access, as that ecosystem scales.
