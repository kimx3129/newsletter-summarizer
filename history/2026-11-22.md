## ✅ VERIFIED — [agentscope-ai/agentscope — framework for transparent, trustworthy multi-agent AI systems](https://github.com/agentscope-ai/agentscope)
**Source:** GitHub

Open-source, production-ready agent framework ("Build and run agents you can see, understand and trust") with a ReAct-style SDK (structured output, realtime interruption/resume, concurrent tool execution, MCP server/skills support), an Agent Service FastAPI backend with web UI, multi-tenancy, and leader-worker multi-agent teams. Apache-2.0, Python 3.11+, ~36.4k stars, 3.9k forks. Recent additions: realtime voice agents (WebRTC), SOP-based task execution, TeamPipeline, model routing.

**Why it matters:** a well-starred, Apache-licensed alternative to LangGraph/CrewAI/AutoGen that ships with a deployable, multi-tenant service layer baked in.

## ✅ VERIFIED — [Tracer-Cloud/opensre — open-source autonomous agent for CI/CD reliability](https://github.com/Tracer-Cloud/opensre)
**Source:** GitHub

Open-source CLI agent (public alpha, Apache-2.0) for CI/CD reliability: reads CI logs, investigates failed runs, correlates commits/deploys, classifies CI-infra vs. code-caused failures, and can push proposed fixes to PR branches for human review; also investigates production incidents. Integrates with Grafana, Datadog, CloudWatch, Sentry, Kubernetes, AWS, Azure, ArgoCD, GitHub/GitLab, Jenkins, PagerDuty, Slack, Discord, Telegram. ~14.0k stars, 1.9k forks, 64 watchers. Self-hostable with local LLMs (Ollama), optional data masking.

**Why it matters:** a self-hostable, root-cause-first alternative to generic CI alerting tools.
