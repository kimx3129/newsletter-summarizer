# 📰 Tech/AI Daily Digest — November 4, 2026

Note: Today's collection was abnormally narrow — a sandbox network restriction blocked all sources except GitHub Trending (Hacker News, arXiv, Reddit, and all company/blog RSS feeds were unreachable), so all 7 stories below are GitHub-Trending-sourced dev tools/models rather than the usual broader mix.

1. **agent-desktop (vercel-labs/agent-desktop)** — https://github.com/vercel-labs/agent-desktop
   Source: GitHub Trending
   Summary: Rust CLI/MCP server letting AI agents control desktop apps via the OS accessibility tree (macOS AX API, Windows UI Automation, Linux AT-SPI) — JSON snapshots with per-element refs, verify-and-retry action loop. ~12.7k stars (+3,791 today). Cross-platform, Apache-2.0.
   Why it matters: Standardized, model-agnostic way for agents to control any desktop app without pixel-based screen scraping.
   Status: ✅ verified

2. **nanochat (karpathy/nanochat)** — https://github.com/karpathy/nanochat
   Source: GitHub Trending
   Summary: Andrej Karpathy's minimal end-to-end codebase for training a ChatGPT-style LLM from scratch (tokenize/pretrain/finetune/eval/chat) on a single GPU node. ~60.2k stars (+479 today), MIT.
   Why it matters: Dramatically lowers the cost/complexity barrier to understanding or experimenting with full LLM training pipelines.
   Status: ✅ verified — note: ~2hr/8xH100/$48 (as low as ~$15 on spot) training-cost claim is author-reported, not independently verified.

3. **copilot-cli (github/copilot-cli)** — https://github.com/github/copilot-cli
   Source: GitHub Trending
   Summary: GitHub's official terminal CLI running the Copilot coding agent locally/synchronously. Defaults to Claude Sonnet 4.5 (switchable via /model), ships GitHub's MCP server plus custom MCP support, requires active Copilot subscription. ~11.3k stars (+13 today).
   Why it matters: GitHub standardizing its coding-agent UX around a terminal-first, MCP-extensible tool — and defaulting to Claude Sonnet 4.5 rather than an OpenAI model.
   Status: ✅ verified

4. **colibri (JustVugg/colibri)** — https://github.com/JustVugg/colibri
   Source: GitHub Trending
   Summary: Pure-C inference engine tiering MoE model experts across GPU/RAM/NVMe by usage frequency. ~47.2k stars (+802 today), Apache-2.0.
   Why it matters: Could meaningfully extend how large a model runs locally on commodity hardware, if benchmarks hold up under independent testing.
   Status: ⚠️ unverified: author-reported GLM-5.2 (744B params) decode-speed benchmarks (0.05-0.1 tok/s on a 25GB laptop up to 9.0-9.2 tok/s on a 6x RTX 5090 rig — not single consumer hardware) are unconfirmed and not independently tested.

5. **Scrapling (D4Vinci/Scrapling)** — https://github.com/D4Vinci/Scrapling
   Source: GitHub Trending
   Summary: Python (3.10+) web scraping framework: HTTP requests, stealth browser automation, parsing, crawling, with Cloudflare Turnstile/Interstitial bypass claims and a built-in MCP server. ~94.8k stars (+1,658 today), BSD-3-Clause.
   Why it matters: Packages stealth scraping and Cloudflare evasion as an agent-ready MCP tool, lowering the barrier for AI agents to scrape bot-blocking sites.
   Status: ✅ verified

6. **worktrunk (max-sixty/worktrunk)** — https://github.com/max-sixty/worktrunk
   Source: GitHub Trending
   Summary: Rust CLI for managing Git worktrees so multiple AI coding agents (Claude Code, Codex) each get an isolated directory and can run in parallel (targeting 5-10+ concurrent agents). ~10.5k stars (+438 today), dual MIT/Apache-2.0.
   Why it matters: Addresses real friction in running multiple coding agents simultaneously on the same repo — increasingly common as agentic coding tools proliferate.
   Status: ✅ verified

7. **portal-ai-plugins (spotify/portal-ai-plugins)** — https://github.com/spotify/portal-ai-plugins
   Source: GitHub Trending
   Summary: Spotify's own plugins connecting its "Portal" developer platform (not a general AI plugin framework) to AI coding agents (Claude Code, Codex, Cursor, pi) — catalog search, service health/ownership briefings, Portal actions with dry-run previews, "Fleetshift" migration shifts incl. opening PRs. ~3.0k stars (+91 today), Apache-2.0, only 9 commits on main.
   Why it matters: A large tech company wiring internal developer-platform tooling directly into third-party AI coding agents — an early concrete pattern for enterprise AI-agent integration, though early-stage (low commit count).
   Status: ✅ verified
