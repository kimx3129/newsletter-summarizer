6. ✅ VERIFIED — **[heretic — fully automatic censorship removal for language models](https://github.com/p-e-w/heretic)**
   - Source: GitHub
   - Summary: Open-source CLI automatically strips refusal/safety alignment from open-weight LLMs via automated "abliteration," no retraining. Orthogonalizes weight matrices against harmful-vs-harmless residual directions using an Optuna TPE sampler; on Gemma-3-12B cut refusals from 97/100 to 3/100 at KL divergence 0.16 (vs. 0 for the original model). Supports dense, multimodal, and multiple MoE/hybrid transformer architectures; 33.4k GitHub stars, AGPL-3.0 license.
   - Why it matters: One-command automated guardrail removal lowers technical bar for uncensored LLMs, intensifies open-weight safety debate.
