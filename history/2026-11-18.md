# 📰 Tech/AI Daily Digest — 2026-11-18

> Note: Source coverage was narrower than usual today — most non-GitHub sources (HN, arXiv, Reddit, company blogs, general RSS) were blocked by network/DNS restrictions upstream in the collector. All 8 stories below came from GitHub Trending only.

1. **[Cursor plugin specification and official plugins](https://github.com/cursor/plugins)** — GitHub
   Cursor's team published cursor/plugins defining a plugin spec (.cursor-plugin/plugin.json manifest, skills/, rules/, mcp.json, root marketplace.json) with 100+ plugins listed. ~16.9k stars, 1.8k forks, MIT-licensed, no tagged releases yet.
   Why it matters: Gives developers a standard way to extend Cursor with portable, shareable plugins instead of ad-hoc configs.

2. **[LoopForge](https://github.com/Tencent/LoopForge)** — GitHub
   Tencent's self-hosted platform orchestrating coding-agent CLIs (Codex, Claude Code, CodeBuddy, +7 others: OpenCode, Cursor CLI, Antigravity, Kimi Code, Pi, DeepSeek Harness, ZCode) via visual-canvas SOPs with human-gate nodes. ~3.1k stars, 436 forks, MIT-licensed. Includes "LoopForge Local" via npx.
   Why it matters: Standardizes multi-agent coding workflows with human approval checkpoints, letting teams mix and match different vendors' coding-agent CLIs.

3. **[RAG-Anything](https://github.com/HKUDS/RAG-Anything)** — GitHub
   HKUDS all-in-one multimodal RAG framework on LightRAG; builds a multimodal knowledge graph with hybrid vector/graph retrieval; parses PDFs/Office/images via MinerU/Docling/PaddleOCR (arXiv:2510.12323). ~24.6k stars, 2.9k forks, MIT.
   Why it matters: Extends RAG beyond plain text to images, tables, and equations in one pipeline, closing a common gap in document-heavy use cases.

4. **[AutoSwarm](https://github.com/HKUDS/AutoSwarm)** — GitHub
   HKUDS framework coordinating multiple heterogeneous coding agents (Codex, Claude Code, Cursor, Copilot CLI, DeepSeek Harness, +7 others) on one task via parallel execution + synthesis (arXiv:2610.33048). ~2.6k stars, 436 forks, MIT.
   Why it matters: Lets teams get the best of multiple coding agents on a single task via parallel execution and result synthesis, rather than betting on one vendor.

5. **[minimind](https://github.com/jingyaogong/minimind)** — GitHub
   Apache-2.0 full-pipeline LLM training code (pretrain/SFT/LoRA/DPO/PPO/GRPO/CISPO/agentic RL/distillation). Flagship ~64M param dense model trains in ~2.3hr/~3 RMB on a single RTX 3090; 198M-total/~64M-active MoE variant also available. ~65.9k stars, 8.7k forks.
   Why it matters: Demonstrates a complete, reproducible LLM training pipeline cheap and fast enough to run on a single consumer GPU, useful for education and experimentation.

6. **[stitch-skills](https://github.com/google-labs-code/stitch-skills)** — GitHub
   Google Labs' Agent Skills library for its Stitch MCP server; 3 plugins (stitch-design, stitch-build, stitch-utilities) usable from Claude Code, Cursor, Codex, Gemini CLI. ~10.1k stars, 1.3k forks, Apache-2.0. Not an officially supported Google product.
   Why it matters: Gives coding agents structured, reusable skills for working with Stitch's design/build/MCP workflow instead of ad-hoc prompting.

7. **[graphify](https://github.com/Graphify-Labs/graphify)** — GitHub
   Local knowledge-graph builder from codebase+docs+PDFs via tree-sitter (~40 languages, zero LLM calls for parsing); exposes a /graphify skill for Claude Code, Cursor, Codex, Gemini CLI. Claims recall@10 0.497 on LOCOMO vs 0.048 (mem0) / 0.149 (supermemory), and 76% QA accuracy on LongMemEval-S (self-reported benchmarks). Dual Apache-2.0/MIT.
   ⚠️ unverified: GitHub shows ~149.7k stars/14.4k forks, but this is almost certainly inflated — the repo is only ~7 months old with zero independent press coverage, which is implausible for organic growth at that scale. Treat the star count with skepticism; don't read it as a genuine popularity signal.
   Why it matters: A zero-LLM-call, local-first alternative to vector-store memory/RAG is a meaningful architectural bet if the self-reported benchmarks hold up, but verify independently before trusting its popularity.

8. **[dograh](https://github.com/dograh-hq/dograh)** — GitHub
   Self-hostable voice AI platform positioned as "the open-source alternative to Vapi & Retell." Visual workflow builder, telephony integrations (Twilio/Vonage/Telnyx/Plivo/etc.), BYOK STT/LLM/TTS, MCP server. ~6.2k stars, 1.6k forks, BSD 2-Clause.
   Why it matters: Offers a self-hostable, provider-agnostic path for voice AI that avoids vendor lock-in to closed platforms like Vapi or Retell.
