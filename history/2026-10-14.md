1. **[Unlimited-OCR](https://github.com/baidu/Unlimited-OCR)** — Source: GitHub (baidu) — ✅ verified
Baidu's one-shot long-document parsing model: handles single images, multi-page documents, and PDFs in one pass via "gundam" (640px) or "base" (1024px) resolution modes, up to 32,768 output tokens, n-gram repetition control.
Runs on Transformers, vLLM, or SGLang; evaluated on OmniDocBench; builds on DeepSeek-OCR/DeepSeek-OCR-2/PaddleOCR lineage. MIT license.
Why it matters: Open, permissively licensed long-document OCR that handles arbitrarily long inputs in one shot removes a major pain point (chunking/stitching) for document-heavy AI pipelines.

2. **[PersonaPlex](https://github.com/NVIDIA/personaplex)** — Source: GitHub (NVIDIA) — ✅ verified
NVIDIA's open code release for a real-time full-duplex speech-to-speech model fine-tuned from Kyutai's Moshi (Helium backbone), with persona control via text prompts and voice control via audio conditioning.
Ships 18 voice presets (8 natural, 10 varied); trained on synthetic dialogue plus the Fisher English Corpus. Code MIT-licensed; weights use NVIDIA's Open Model license.
Why it matters: A permissively-licensed, low-latency voice assistant stack with persona/voice steering gives developers a ready alternative to closed real-time voice APIs.

3. **[skills](https://github.com/vercel-labs/skills)** — Source: GitHub (vercel-labs) — ✅ verified (corrected)
Vercel Labs' `npx skills` CLI for installing and managing agent "SKILL.md" files across Claude Code, Codex, Cursor, OpenCode, and roughly 75 other coding agents (about 79 total — corrected from an initial "75+" flat-count claim).
Supports installing skills from GitHub, GitLab, Azure Repos, arbitrary git URLs, local paths, or direct download links, at project or global scope, via symlink or copy. Follows the agentskills.io Agent Skills spec, integrates with Claude Code's plugin marketplace. MIT-licensed, optional anonymous telemetry.
Why it matters: A single cross-agent CLI for the emerging "agent skills" standard reduces fragmentation as more coding agents adopt reusable skill files.
